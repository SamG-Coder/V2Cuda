Your live shader workspace

        
      

      

        V2Cuda generates CUDA from the connected node graph, compiles it to WGSL, and runs a 3D
        smoke solver and volume renderer on WebGPU.
      

      

        
Connect nodes

        

          Click an output socket, then a matching input. Right-click an input or wire to disconnect.
        

        
Navigate

        

          Drag nodes to arrange. Drag empty graph space to pan; scroll to zoom. Drag the viewport to
          orbit.
        

        
Animate

        

          Pause, select a property, change its value, then click its diamond to insert a keyframe.
          Scrubbing replays and caches the actual simulation.
        

        
Inspect the shader

        

          The CUDA and WGSL tabs show the exact generated source and installed kernels. Errors
          preserve the last valid running shader.
        

        
Shortcuts

        

          Space: play / pause · Ctrl Z: undo · Ctrl Shift Z: redo · Ctrl S: save project · Delete:
          remove node · F: fit graph
        

      

      

        This is a bounded smoke authoring system. Particle simulation, collision geometry, VDB and
        arbitrary CUDA editing are not implemented.
